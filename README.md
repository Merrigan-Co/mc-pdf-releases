# MC PDF engine releases

Compiled builds of the MC PDF engine, the program behind Merrigan & Co.'s `mc-pdf` plugin for Claude Code. The plugin makes accessible PDF/UA-1 versions of PDFs that look like the originals, on your own computer.

This repository only holds releases. There's no source code here.

**You don't need to download anything from here yourself.** The plugin's setup step does it, asking you first. It also checks each file against the release's `SHA256SUMS.txt` before installing it.

| File | For |
|---|---|
| `mcpdf-macos-arm64.zip` | Macs with Apple silicon |
| `mcpdf-macos-x64.zip` | Intel Macs |
| `mcpdf-windows-x64.zip` | Windows 10 and 11 (64-bit) |
| `THIRD-PARTY-NOTICES.txt` | The open-source components inside the engine, and their licences |

Questions: ask Merrigan & Co.
